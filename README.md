Simple project intented to learn some new stuff. Nest, Jest, Clean Arch, Solid, Typescript.

## Installation

```bash
$ npm install
```


## Running the app

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

## Migrations

```bash
# create migration
$ npm run migration:create -n migration-name
$ npm dev:migration:run

```
