## Installation

```bash
$ npm install
```


## Running the app

```bash
# development
$ yarn dev
```

## Migrations

```bash
# create migration
$ yarn migration:create -n migration-name
$ yarn dev:migration:run

```

## Tests

```bash
# create migration
$ yarn test

```
